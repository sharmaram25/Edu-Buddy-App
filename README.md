## ✨ Overview

**Edu-Buddy** is a comprehensive educational management application designed to help students organize their academic life. With features for tracking assignments, managing lectures, monitoring expenses, and organizing events, Edu-Buddy is the all-in-one solution for staying on top of your educational journey.

## 🚀 Features

- **📊 Dashboard** - Get an overview of your academic life at a glance
- **📚 Assignments** - Track homework, projects, and submission deadlines
- **🎓 Lectures** - Organize your class schedule and lecture notes
- **📆 Events** - Keep track of important academic events and activities
- **💰 Expenses** - Monitor your educational expenses and budget
- **✅ Tasks** - Manage to-do lists for better productivity
- **🔔 Notifications** - Never miss important deadlines or events

## 💻 Tech Stack

- **Frontend**: React with TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Routing**: React Router DOM
- **Database**: Supabase
- **Build Tool**: Vite
- **Icons**: Lucide React

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/sharmaram25/Edu-Buddy-App.git
   cd Edu-Buddy-App
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment setup**  
   Create a `.env` file in the root directory with your Supabase credentials:
   ```
   VITE_SUPABASE_URL=your-supabase-url
   VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```

5. **Build for production**
   ```bash
   npm run build
   ```
